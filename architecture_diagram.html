Architectural Summary & Subsystem Highlights
1. Hardware Inputs & E-Paper Display
Operates directly on Raspberry Pi GPIO pins (Up, Down, Enter, Special) using pull-up resistor sensing. Controls a Waveshare 2.13" E-Paper display via SPI, rendering monochrome 1-bit menus, preview images, and solution pages with 270° rotation.
2. Core State Machine & Memory Cache
Features a 7-state Finite State Machine (FSM) handling navigation, multi-capture queues (up to 12 images), and local settings persistence via settings_cache.json. Stores up to 3 recent solution image pages in RAM history for offline review.
3. Network Engine & Mobile Hotspot
Encapsulates REST HTTP requests with x-board-key security headers. Includes a dedicated background daemon sending 60-byte DNS socket pings every 30 seconds to keep iPhone/Android mobile hotspots from going idle.
4. Vercel Backend & AI Solvers
Connects to Vercel Serverless endpoints (/api/ask, /api/status). Utilizes asynchronous long-polling (up to 10 mins) while cloud Vision-Language Models (GPT-4o, Claude 3.5, Gemini 1.5) solve visual problems and return Base64 solution pages.
